# Quicken row editing: inline buttons, entry bar, keyboard, leaving a changed row, Split

Research for [#365](https://github.com/StanleyGoldman/balanced/issues/365). It feeds #356, the row-level editing prototype.

Researched 2026-10-20 in two passes, from Quicken's own help pages (Quicken for Windows, also called Quicken Classic, plus a few Quicken for Mac pages for contrast). Nothing was checked against a running copy of Quicken. Quicken's help covers little of the row-editing detail, so several points stay unconfirmed. The second pass added a university extension manual with Quicken 2015 screenshots, and a separate section on other registers (GnuCash from its manual and source code, YNAB from its help centre, Microsoft Money from what little survives).

## Question

How does Quicken behave while a Register row is edited: the inline buttons, the entry bar, the keyboard, the prompt on leaving a changed row, and the Split flow?

## Answer in brief

- **Buttons:** the help pages name a **Save** button and a **Split** icon on the transaction toolbar, and a **gear icon** on the same toolbar that holds per-transaction actions (Delete, Attachments; Memorize payee per a Quicken 2015 manual). No Windows help page uses the labels "Enter", "Record" or "More actions". The row buttons sit in an **Action buttons** register column that "always appears last and can't be moved". A Quicken 2015 manual shows Save, gear and split at the right end of the selected row's second line in two-line mode. Which buttons appear only on a new transaction is unconfirmed. Quicken for Mac differs: it has no Save step and puts Split and **Edit Details** buttons on the row.
- **Entry bar:** no help page describes an entry-bar mode for the banking register. The shortcuts page lists an **Enter Transaction dialog** (Ctrl+5, "accessibility feature"), but no page describes it. Investment transactions are edited in a form opened from an **Edit** button on the transaction toolbar.
- **Keyboard:** **Enter or Ctrl+Enter** records, **Ctrl+S** opens Split, **Ctrl+N** goes to a new transaction, **Ctrl+D** deletes a transaction or split line, **Tab / Shift+Tab** move between fields. A preference lets Enter move between fields; a university extension manual confirms that Ctrl+Enter or the Save button then records. **Esc** restores (undoes) an edit.
- **Leaving a changed row:** Quicken's help says that if you leave a transaction, change column sizes or do other file operations before clicking Save, "Quicken asks you to confirm any changes you made and then saves them." Two Notify preferences relate to this warning. The prompt's exact text and buttons, and behaviour for an invalid row, are unconfirmed. Quicken for Mac saves on leaving with no prompt.
- **Split:** opens a dialog from the Split icon; lines are not committed until OK then Save (unless "Automatically Enter Split Data" is on). The remainder shows below the last line with Adjust, Allocate and Edit options. Esc in the dialog is unconfirmed.
- **More actions menu:** the nearest Quicken equivalent is the gear icon on the transaction toolbar. Whether an unedited row shows a different menu is unconfirmed for the banking register.
- **Other registers:** GnuCash's leave-a-changed-row prompt is confirmed from source: "Save the changed transaction?" with **Discard Changes / Cancel / Record Changes** and two "remember" checkboxes; an unbalanced transaction gets a separate Rebalance dialog and the cursor stays put. See the labelled section.

## 1. Buttons on the edited row

- The change-a-transaction steps are: select the transaction, edit the fields in place, "Click **Save** to record the changes." ([Change a spending transaction](https://info.quicken.com/win/change-a-spending-transaction), [Edit a transaction](https://info.quicken.com/win/edit-a-transaction)) Neither page mentions Enter, Split or Actions buttons.
- The new-transaction steps end "Click Save." and mention "click the Split button" for several categories. ([Enter a spending transaction](https://info.quicken.com/win/enter-a-spending-transaction))
- The split steps say "On the transaction toolbar, click the 'Split' icon" and "Click 'Save' on the transaction toolbar to enter the transaction in the register." ([Record a split transaction](https://www.quicken.com/support/record-split-transaction/)) The label is Save, not Enter.
- **Gear icon (per-transaction actions):** to delete, "click the gear icon … in the transaction toolbar and then choose Delete", then Yes to confirm. ([How do I void or delete a transaction](https://www.quicken.com/support/how-do-i-void-or-delete-transaction/)) To attach a file, click the gear icon "in the transaction toolbar and choose Attachments." ([Attach a bill, receipt or other image](https://info.quicken.com/win/how-do-i-attach-a-bill-receipt-or-other-image-to-a)) No help page found lists the gear menu in full.
- **Action buttons column:** in the register column chooser, "**Action buttons** always appears last and can't be moved." The page does not name the buttons in it. ([Customize the register](https://info.quicken.com/win/customize-the-register))
- **Investment registers differ:** "On the transaction toolbar, click Edit", then "Make your changes in the form, then click Enter/Done to save." ([Edit a transaction](https://info.quicken.com/win/edit-a-transaction)) To delete an investment transaction, "click Delete directly under the transaction." ([How do I void or delete a transaction](https://www.quicken.com/support/how-do-i-void-or-delete-transaction/))
- The Register Action Bar above the register is a separate, customizable row of account-level buttons, reached from Account Actions → Customize Action Bar. It is not the row's buttons. ([Customize the register action bar](https://info.quicken.com/win/how-do-i-customize-the-register-action-bar))
- **Placement (Quicken 2015, university manual):** the Ohio State University Extension Quicken 2015 manual tells users to "Click Split Icon (split arrow) near the Save Button" and to "Click the Gear Icon beside the Save button on the transaction line. Click Memorize payee…". Its screenshot of a just-recorded transaction in two-line mode shows a Save button, a gear and a split icon at the right end of the selected row's second line, under the Balance column. ([OSU Extension, Quicken 2015 manual, ch. 5, pp. 44 and 54](https://agnr.osu.edu/sites/agnr/files/imce/Feb19Quicken/02.18.19-Quicken-2015.pdf)) This is a teaching manual, not Quicken documentation, and covers a 2015 release.
- **Quicken for Mac (contrast):** while editing, "select the **Split** button" on the register row, or "the **Edit Details** button on the selected row then select the **Splits tab**". ([Split transactions (Mac)](https://info.quicken.com/mac/split-transactions)) "Click **Edit Details** in the middle of the register row" opens extra fields. ([Entering transactions (Mac)](https://info.quicken.com/mac/entering-transactions))
- Unconfirmed: which buttons appear only on a new transaction; whether "Save" is ever labelled "Enter" on a banking register row; differences between current Quicken Classic releases and the 2015 layout.

## 2. Entry bar

- No Quicken help page found describes an entry-bar mode for the banking register.
- The keyboard shortcuts page lists "Open the Enter Transaction dialog (accessibility feature)": CTRL+5. ([Keyboard shortcuts in Quicken](https://info.quicken.com/win/keyboard-shortcuts-in-quicken)) No page found describes what the dialog holds. The accessibility options page does not mention it. ([Set Quicken accessibility options](https://info.quicken.com/win/set-quicken-accessibility-options))
- Investment transactions use a form opened by the Edit button (section 1), which is the nearest form-based editing Quicken documents.
- Unconfirmed: whether the Enter Transaction dialog is an entry-bar equivalent, and its fields.

## 3. Keyboard

- **Shortcuts page, Register and Write Checks section:** "Record a transaction": ENTER or CTRL+ENTER. "Open the Split Transaction dialog": CTRL+S. "Go to a new transaction": CTRL+N. "Insert a transaction": CTRL+I. "Delete a transaction or split line": CTRL+D. "Memorize a transaction": CTRL+M. "Void a transaction": CTRL+V. "Copy data from the field above the currently selected field in the Split Transaction dialog": ' (apostrophe). Moving around: TAB "Next field or column", SHIFT+TAB previous, HOME twice "First field in transaction", END twice "Last field in transaction". The page lists no Esc shortcut. ([Keyboard shortcuts in Quicken](https://info.quicken.com/win/keyboard-shortcuts-in-quicken))
- **Ctrl-key scheme:** Edit → Preferences → Setup has a keyboard mapping choice between "Quicken Standard" and "Windows Standard - Undo/Cut/Copy/Paste", which changes what CTRL+Z/X/C/Y do. ([Setup preferences](https://info.quicken.com/win/setup-preferences)) So Ctrl+V as Void depends on that choice; the two pages do not agree on which letters are remapped (the setup page names Y, the shortcuts page Z/X/C/V).
- **Enter key preference:** Data entry and QuickFill preferences has "Use enter key to move between fields": "Lets you use the Enter key, in addition to Tab, to move between fields in the register and the Write Checks window." ([Data entry and QuickFill preferences](https://info.quicken.com/win/data-entry-and-quickfill-preferences)) Quicken's help does not say how to record while it is on. A university extension guide says that if you choose to use Enter to move, "you will have to use [Ctrl + Enter] or use your mouse to click the [Save] button" to record. ([Oklahoma State Extension, Recording transactions](https://extension.okstate.edu/programs/farm-management-and-finance/quicken-for-farm-financial-records/site-files/docs/recording-transactions.pdf), quoted from a search summary; the PDF returned 403 to a direct fetch.) Treat the swap as likely but not confirmed by Quicken itself.
- **Esc:** to undo an edit, select the transaction and "Either choose Edit menu > Transaction > Restore Transaction, or press the Esc key." ([Edit a transaction](https://info.quicken.com/win/edit-a-transaction))
- **Quicken for Mac (contrast):** "You don't need to click **Save** to save a transaction. … The app records the transaction when you press Enter, move to another task, or close the register." Undo is Edit → Undo (⌘Z). ([Entering transactions (Mac)](https://info.quicken.com/mac/entering-transactions)) Mac register settings let you turn Tab-to-next-field on or off in date fields. ([Register settings (Mac)](https://info.quicken.com/mac/register-settings))
- Unconfirmed: Tab at the last cell (into the buttons, round to the first cell, or recording); focus after Record or after Esc; whether Enter in a QuickFill drop-down picks the item or records.

## 4. Leaving a changed row

- Quicken's help: "If you leave a transaction, change column sizes, or do other file operations before clicking Save, … Quicken asks you to confirm any changes you made and then saves them." It adds: "You can turn this reminder off by clearing the Before changing existing transactions check box in the Notify Preferences dialog." ([Edit a transaction](https://info.quicken.com/win/edit-a-transaction))
- Edit → Preferences → Notify has seven checkboxes, including **To save a transaction after changing it**: "Select this preference to be warned if you change a transaction and then forget to save it", and **Before changing existing transactions**: "This preference helps you avoid inadvertently changing a transaction that you've already entered." ([Notify preferences](https://info.quicken.com/win/notify-preferences)) The two pages disagree on which checkbox controls the leave-row reminder; the Edit page names "Before changing existing transactions", while the Notify page's description of "To save a transaction after changing it" fits it better.
- So with the reminder off, Quicken's documented behaviour is not to discard: the reminder is a confirmation before saving. Whether turning it off saves silently or discards is not stated. Unconfirmed.
- Changing a reconciled transaction: "Quicken lets you know if you're about to change a reconciled transaction and asks you to confirm the change." ([Edit a transaction](https://info.quicken.com/win/edit-a-transaction))
- Quicken for Mac has no prompt: it records the transaction when you "move to another task, or close the register". ([Entering transactions (Mac)](https://info.quicken.com/mac/entering-transactions))
- Unconfirmed: the prompt's exact text, its button labels, behaviour when the changed row is invalid. (Compare GnuCash's prompt in the other-registers section, which is confirmed from source.)

## 5. Split

- Open: select the transaction, click the Split icon on the transaction toolbar, or Ctrl+S. ([Record a split transaction](https://www.quicken.com/support/record-split-transaction/), [Keyboard shortcuts in Quicken](https://info.quicken.com/win/keyboard-shortcuts-in-quicken)) Another help page opens it from the Category field: "Click the Category icon", then "Click Split." ([How do I record a split transaction](https://info.quicken.com/win/how-do-i-record-a-split-transaction))
- The Split Transaction dialog takes a category, optional tag and amount per line. "Add lines" adds rows (up to 250), "Clear All" resets, "Edit" inserts or deletes a line. ([Record a split transaction](https://www.quicken.com/support/record-split-transaction/)) Ctrl+D deletes a split line; apostrophe copies the field above. ([Keyboard shortcuts in Quicken](https://info.quicken.com/win/keyboard-shortcuts-in-quicken))
- Pending: "Click OK to close the Split Transaction dialog" ([How do I record a split transaction](https://info.quicken.com/win/how-do-i-record-a-split-transaction)), then Save enters the transaction, "You can skip this step if the register preference 'Automatically Enter Split Data' is turned on." ([Record a split transaction](https://www.quicken.com/support/record-split-transaction/)) The register preference reads "Automatically enter split data: Select this option to be able to enter a transaction from the split dialog." ([Register preferences](https://info.quicken.com/win/register-preferences)) So lines are pending until Save by default.
- Remainder: when the Split Total differs from the Transaction Total, "Quicken shows the leftover amount below the last split line." Fixes: change line amounts; **Adjust** sets the Transaction Total to the Split Total; Edit → "Apply remainder to current line"; Edit → "Allocate this line to other split lines"; **Allocate** spreads the leftover. ([Record a split transaction](https://www.quicken.com/support/record-split-transaction/), [How do I record a split transaction](https://info.quicken.com/win/how-do-i-record-a-split-transaction))
- Quicken for Mac edits splits in a **Splits** tab of Edit Details rather than a dialog, adds rows with "+" or Shift+⌘N, and handles remainders automatically: for a new transaction "The total amount is automatically calculated"; for an existing one Quicken adds a remainder line, or adjusts the previous line when income and expense are mixed. ([Split transactions (Mac)](https://info.quicken.com/mac/split-transactions))
- Unconfirmed: Esc or Cancel inside the Windows dialog and what happens to edited lines; inline split lines in the Windows register.

## 6. More actions menu

- The nearest Quicken equivalent is the **gear icon in the transaction toolbar**, documented to hold Delete and Attachments (section 1), and per the OSU Quicken 2015 manual, Memorize payee. Right-clicking a field in the transaction offers "Void transaction(s)" per the same manual (p. 45). ([OSU Extension, Quicken 2015 manual](https://agnr.osu.edu/sites/agnr/files/imce/Feb19Quicken/02.18.19-Quicken-2015.pdf))
- In the Customer Invoices register (Quicken Home & Business), you "Hover over the row until the gear icon appears at the far right", which offers "Form…". ([How do I enter or edit a transaction in the register?](https://info.quicken.com/win/how-do-i-enter-or-edit-a-transaction-in-the-regist)) So at least one register shows a per-row gear on hover, not only on the edited row.
- Unconfirmed: the full gear menu; whether an unedited banking row shows the same menu; any item labelled "More actions".

## Secondary sources (not Quicken documentation)

- **Quicken Community, search summaries only** (threads need sign-in and could not be fetched): Ctrl+Enter saves in non-investment registers regardless of the Enter preference; with the Enter-moves-fields option off, Tab moves and Enter saves, and with it on, Enter moves and Ctrl+Enter saves. One user reports the save warning not appearing with "To save a transaction after changing it" ticked, and another that the prompt appears only for a changed existing transaction, not a new unsaved one. The Save, Split and gear icons come from the "Action Buttons" register column; in two-line mode they sit on the second line below Balance. With "Automatically enter split data" on, the split dialog shows Enter and Cancel instead of OK and Cancel. ([Notify search summary](https://community.quicken.com/discussion/comment/20326483), [shortcut thread](https://community.quicken.com/discussion/comment/20151426), [not prompted to save](https://community.quicken.com/discussion/7926593/not-being-prompted-to-save-when-moving-off-a-changed-or-new-transaction), [buttons in the corner](https://community.quicken.com/discussion/comment/20089565), [automatically enter split data](https://community.quicken.com/discussion/comment/20336969))
- **University extension manuals:** OSU Extension's Quicken 2015 manual and Oklahoma State Extension's recording-transactions guide, cited above where used. They describe real Quicken releases but are not Quicken's own documentation.

## Other registers (not Quicken)

For comparison only. These describe how other programs behave, not Quicken.

### GnuCash

- **Leaving a changed transaction, from source:** moving the cursor to another transaction after changing the current one shows a dialog titled "Save the changed transaction?" with the text "The current transaction has been changed. Would you like to record the changes before moving to a new transaction, discard the changes, or return to the changed transaction?" and buttons **Discard Changes**, **Cancel**, **Record Changes**. Discard reverts the edits and completes the move; Cancel keeps the cursor on the changed transaction. ([split-register-control.cpp, `transaction_changed_confirm`](https://github.com/Gnucash/gnucash/blob/stable/gnucash/register/ledger-core/split-register-control.cpp))
- **The "always" equivalent, from source:** that dialog runs through `gnc_dialog_run`, which adds two checkboxes, "Remember and don't ask me again." and "Remember and don't ask me again this session.", and focuses Cancel by default. A remembered answer is returned without showing the dialog; Cancel and closing the window are never remembered. ([dialog-utils.c, `gnc_dialog_run`](https://github.com/Gnucash/gnucash/blob/stable/gnucash/gnome-utils/dialog-utils.c))
- **Invalid (unbalanced) row, from source:** when the cursor leaves a transaction that does not balance, a "Rebalance Transaction" dialog says "The current transaction is not balanced." and offers "Balance it manually", "Let GnuCash add an adjusting split", "Adjust current account split total" and "Adjust other account split total", with a Rebalance button; the cursor then stays on the transaction "so the user can see what happened". ([split-register-control.cpp, `gnc_split_register_balance_trans`](https://github.com/Gnucash/gnucash/blob/stable/gnucash/register/ledger-core/split-register-control.cpp))
- **Enter and Tab, from the manual:** "The Enter key moves to the first field of the next split, regardless of which field you are in. If there is no next split, proceeds to the next transaction. In any case, Enter finishes the transaction edit", posting any imbalance to Imbalance-CUR. "The Tab key moves to the next field in the current split. If it's the last field, moves to the next split, creating a new one if there isn't one. If the split is blank, the Tab key finishes the transaction." ([GnuCash manual, Enter Transaction via register](https://code.gnucash.org/docs/C/gnucash-manual/trans-enter.html))
- **Focus after Enter, from the settings schema:** "'Enter' key moves to bottom of register": "If active, pressing the enter key will move to the bottom of the register. Otherwise pressing the enter key will move to the next transaction line." Default off. ([org.gnucash.GnuCash.gschema.xml.in](https://github.com/Gnucash/gnucash/blob/stable/gnucash/gschemas/org.gnucash.GnuCash.gschema.xml.in))
- **Toolbar, from the manual:** Enter (record), Cancel ("Selecting the Cancel icon or going to Transaction → Cancel Transaction will erase the transaction"; in context, the entry in progress), Blank (jump to the blank transaction), Split, Jump. ([Enter Transaction via register](https://code.gnucash.org/docs/C/gnucash-manual/trans-enter.html), [The Account Register](https://code.gnucash.org/docs/C/gnucash-guide/txns-registers1.html)) These are register-window toolbar buttons, not buttons on the row.
- **Split, from the manual:** splits are edited inline: "press the Split button on the Toolbar or select Actions → Split Transaction"; each split becomes a register line, an unbalanced amount appears in a blank last row, and "Selecting the next transaction will close the split". ([Multiple Split Transactions](https://code.gnucash.org/docs/C/gnucash-manual/trans-multi-enter.html))
- **Mailing list, search summary only** (from pass one): the Cancel toolbar button reverts uncommitted edits only while the cursor is in the same transaction; a bug report says the save-or-cancel prompt reappeared after "don't ask me again" when switching by click. ([GnuCash list](https://lists.gnucash.org/pipermail/gnucash-user/2019-June/085396.html), [bug 335437](https://bugzilla.gnome.org/show_bug.cgi?id=335437))

### YNAB (web)

- **Keys:** "Commit": Enter or Return. "Cancel": Escape. "Move to the next field or button": Tab; "Move to the previous transaction field": Shift+Tab. "Add new transaction": Shift+N. "Split": S. "Delete": Delete. "Duplicate": Shift+D. Undo Ctrl/⌘+Z. ([YNAB Keyboard Shortcuts](https://support.ynab.com/en_us/keyboard-shortcuts-Skw9Xp9A9.md)) Tab moving to the next "field or button" implies the row's buttons are in the Tab order.
- **Adding:** click "Add Transaction", fill the fields, click "Save". ([How to Add Transactions in YNAB](https://support.ynab.com/en_us/how-to-add-transactions-in-ynab-HyDwA_byi.md))
- **Split:** "Click Add Transaction or double-click to edit an existing transaction", choose Split in the category field, enter the total on the top line and a category and amount on each line that follows, "then tap Save or Update". Split lines show inline under the top line. If an amount remains "next to 'Amount remaining to assign' when you click Save", YNAB prompts to auto-distribute it. ([Split Transactions](https://support.ynab.com/en_us/split-transactions-a-guide-SJLEKwY0q.md)) This suggests the button reads Save on a new transaction and Update on an existing one, but the page does not say so outright.
- Unconfirmed: any prompt on leaving a changed row; a "Save and add another" button; focus after Save.

### Microsoft Money

- No Microsoft documentation found; Money's help shipped with the product and was not published online. A third-party blog lists Esc "to cancel changes", Ctrl+S to split, and Ctrl+Y to copy the same field from the previous transaction in the register, without naming a source. ([Keyboard Shortcuts for Microsoft Money](https://microsoftmoneyoffline.wordpress.com/keyboard-shortcuts-for-microsoft-money/)) Treat as unconfirmed.
